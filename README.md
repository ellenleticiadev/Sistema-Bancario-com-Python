# 🏦 Sistema Bancário com Python

Este projeto apresenta um **Sistema Bancário simples desenvolvido em Python**, com o objetivo de simular operações bancárias essenciais de forma prática e eficiente.

---

## 💻 Sobre o Projeto

O sistema permite realizar as seguintes operações:

- **Depósito:** Adicione valores positivos ao saldo da conta.
- **Saque:** Retire valores do saldo, respeitando o limite de R$ 500 por operação e até 3 saques por sessão.
- **Extrato:** Visualize todas as movimentações realizadas e o saldo atual.
- **Sair:** Encerre a sessão do sistema a qualquer momento.

O código utiliza um menu interativo no terminal, valida todas as operações e atualiza o extrato automaticamente após cada movimentação.

---

## 🚀 Como Usar

1. Execute o código em um ambiente Python.
2. Siga as opções do menu para realizar depósitos, saques ou consultar o extrato.
3. Acompanhe suas movimentações pelo extrato.

---

Este projeto é ideal para quem deseja entender a lógica por trás de um sistema bancário simples e praticar programação em Python.
